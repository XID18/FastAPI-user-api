# FastAPI User API

Учебный REST API на FastAPI с регистрацией, JWT-авторизацией и CRUD-операциями для пользователей.

## Возможности

- Регистрация пользователя
- Вход пользователя через `/login`
- JWT access token
- Защищённый endpoint `/me`
- Получение списка пользователей
- Поиск пользователя
- Получение, обновление и частичное обновление пользователя
- Swagger-документация

## Стек

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- PostgreSQL
- Docker
- JWT / OAuth2
